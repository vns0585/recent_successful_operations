# Виджет последних успешных операций

## О проекте

Данный проект является бэкенд-частью виджета последних успешных операций для личного кабинета клиента банка. 
Его основная задача — подготовка и фильтрация данных для отображения последних успешных банковских операций клиента.

## Основные возможности

1.  **Фильтрация по статусу**: Возвращает только операции с запрошенным статусом (например: `'EXECUTED'`).
2.  **Сортировка по дате**: Упорядочивает операции от самой свежей к самой старой (или наоборот).
3.  **Маскировка конфиденциальных данных**:
    - Номер карты отображается как `XXXX XX** **** XXXX` (например: `1234 56** **** 7890`).
    - Номер счета отображается как `**XXXX` (например: `**1234`).
4.  **Преобразование форматов дат для корректного отображения на фронтенде**: Переводит iso-формат даты в формат ДД.ММ.ГГГГ (например: 2024-03-11T02:26:18.671407, отобразит как 11.03.2024)

## Установка и использование

Проект еще находится на стадии разработки. Следите за обновлениями.

### Требования
- Python 3.13 или выше
- Poetry 2.0.0 или выше

### Установка
1. Клонируйте репозиторий:

'''
git clone https://github.com/vns0585/recent_successful_operations.git
'''

2. Установите зависимости:

'''
poetry install
'''
